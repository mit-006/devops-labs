# ⚙️ Process Management & Monitoring

## 📖 Overview

This task demonstrates Linux process management and system monitoring. 
It includes starting a background process, monitoring its execution, viewing process details, checking system resources, terminating the process, and verifying that it has stopped successfully.

---

## 🎯 Objective

- Start a process in the background.
- Obtain the Process ID (PID).
- Monitor the running process.
- Display the process tree.
- Check memory usage.
- Display CPU information.
- Terminate the background process.
- Verify that the process has stopped.

---

## 🛠 Tasks Performed

- Started a background `ping` process.
- Captured the Process ID (PID).
- Displayed process details using `ps`.
- Listed running processes using `ps aux`.
- Displayed the process hierarchy using `pstree`.
- Checked system memory usage using `free -h`.
- Displayed CPU information using `lscpu`.
- Terminated the background process using `kill`.
- Verified that the process was successfully stopped.

## ✅ Verification

Run the following commands after executing the script:

```bash
ps -fp <PID>

ps aux | grep ping

pstree -p

free -h

lscpu

ps -p <PID>
```

Verify that:

- The `ping` process starts successfully.
- The correct PID is displayed.
- Process information is shown using `ps`.
- Memory and CPU information are displayed.
- The `ping` process is terminated successfully.
- `ps -p <PID>` returns no running process after the `kill` command.

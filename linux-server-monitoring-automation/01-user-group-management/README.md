# 👥 User & Group Management

## 📖 Overview

This task demonstrates basic Linux user and group administration.
It includes creating users and groups, assigning users to groups using different methods, setting user passwords, granting sudo privileges, and verifying the configuration.

---

## 🎯 Objective

- Create a Linux group.
- Create multiple Linux users.
- Add users to a group.
- Assign sudo (wheel) privileges.
- Set user passwords.
- Verify user and group configuration.

---

## 🛠 Tasks Performed

- Created a group named **devops_team**.
- Created two users:
  - `devops_user1`
  - `devops_user2`
- Added `devops_user1` to the group using `usermod`.
- Added `devops_user2` to the group using `gpasswd`.
- Set a password for `devops_user1`.
- Granted sudo (wheel) access to `devops_user1`.

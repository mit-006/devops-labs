Protocols&Ports:
protocols are the rulebooks that computers use to talk to each other,
while ports are the digital doors or channels that direct this incoming data to the right app on your device

---

Most commonly used protocol with their relevance to DevOps

| **Protocol** | **Port** | **Relevance to DevOps**                                                                     |
| ------------ | -------: | ------------------------------------------------------------------------------------------- |
| **HTTP**     |       80 | Used to access web applications, APIs, and application testing.                             |
| **HTTPS**    |      443 | Secure communication for websites, APIs, CI/CD tools, and cloud services.                   |
| **SSH**      |       22 | Securely connects to Linux servers for deployment, automation, and remote management.       |
| **FTP**      |       21 | Transfers files between systems (less commonly used due to security concerns).              |
| **SFTP**     |       22 | Securely transfers application files, backups, and logs between servers.                    |
| **DNS**      |       53 | Resolves domain names to IP addresses so applications and services can communicate.         |
| **DHCP**     |    67/68 | Automatically assigns IP addresses to devices in a network.                                 |
| **SMTP**     |       25 | Sends email notifications from monitoring and CI/CD tools.                                  |
| **SNMP**     |      161 | Monitors the health and performance of servers, switches, and routers.                      |
| **NTP**      |      123 | Synchronizes server time, which is important for logs, monitoring, and distributed systems. |
| **RDP**      |     3389 | Allows remote access to Windows servers for administration.                                 |
| **SMB**      |      445 | Shares files and folders between Windows systems.                                           |

The OSI model:

The OSI (Open Systems Interconnection) Model is a 7-layer networking reference model developed by ISO. It standardizes how data is transmitted between devices over a network.
Each layer has a specific function, making network communication easier to understand, develop, and troubleshoot.


It's 7 layers are:

Physical
Data Link
Network
Transport
Session
Presentation
Application

---

layers with their functions
7. Application:
   Lets users use network services (Web, Email, File Transfer).
6. Presentation:
   Changes data into a readable format, encrypts and compresses data.
5. Session:
   Starts, manages, and ends the connection between two devices.
4. Transport:
   Makes sure data reaches correctly without errors.
3. Network:
   Finds the best path for data to travel using IP addresses.
2. Data Link:
   Sends data between two devices on the same network and checks for errors.
1. Physical:
   Sends data as electrical, optical, or wireless signals through cables or air.

The TCP/IP model:

The TCP/IP (Transmission Control Protocol/Internet Protocol) Model is the networking model used on the Internet.
It defines how data is sent and received between devices. It has 4 layers, and each layer performs a specific function.


It's 4 layers are:

1.Netork Access (Link)
2. Internet
3. Transport
4. Application


layers with their functions:
4. Application:
   Provides services like web browsing, email, and file transfer.
3. Transport:
   Ensures data is delivered correctly using TCP or UDP.
2. Internet:
   Finds the best path and uses IP addresses to send data.
1. Network Access (Link):
   Sends data through cables, Wi-Fi, or other physical networks.

Real world example


OSI Model:
Application → You enter youtube.com in your browser.
Presentation → HTTPS encrypts the data.
Session → A connection is created between your device and YouTube.
Transport → TCP reliably sends and receives data.
Network → IP finds the best route to YouTube's server.
Data Link → Wi-Fi sends data to your router using the MAC address.
Physical → Data travels as radio waves (Wi-Fi) or electrical signals (Ethernet cable).


TCP/IP Model:
Application → Browser requests the YouTube website using HTTP/HTTPS.
Transport → TCP ensures the webpage loads correctly.
Internet → IP routes packets to YouTube's server.
Network Access → Wi-Fi/Ethernet transmits the packets over the local network.

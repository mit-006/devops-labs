# 🧑‍💻 Bash User Automation

A collection of Bash scripts to automate Linux user management tasks 
such as user creation, deletion, password reset, and listing users.

---

## 📁 Project Structure

bash-user-automation/
│── user_creation.sh  
│── user_deletion.sh  
│── user_pass_reset.sh  
│── user_list.sh  
│── user_help.sh  

---

## ⚙️ Features

- Create new user accounts
- Delete existing users
- Reset user passwords
- List all users with UID
- Help guide for usage

---

## 🚀 Usage

Make scripts executable:

```bash
chmod +x *.sh
